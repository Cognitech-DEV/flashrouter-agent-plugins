# Security

This repository is a credential-free client package. Do not commit an account
password, OAuth token, API key, cookie, environment file or customer record.
Client names and skill text grant no authority. The hosted service verifies
native identity, current role/membership and explicit delegation on every call.

Use GitHub's private vulnerability reporting when available. Otherwise contact
the FlashRouter support channel from your authenticated account. Never attach
secrets or customer data to a public issue. Rotate a credential through its
owner if it was exposed; deleting a Git file does not revoke it.
